# YoutubeClipper

YouTube-Abschnitt als WAV-Clips (44,1 kHz, 16-bit, mono) für Second Life.

## VS Code

1. Ordner öffnen.
2. Terminal: `dotnet run`
3. Oder `Strg+Shift+P` → **Tasks: Run Task** → **Start**.

Braucht das .NET 8 SDK. ffmpeg und yt-dlp müssen im PATH liegen, oder als `tools/ffmpeg.exe` und `tools/yt-dlp.exe` im Projektordner.
